## Gotchas that cost THIS conversation real time (append to the estate's list)

- **Stale binaries lie.** A probe against `fusor_mc.exe` measured old physics because
  only test targets had been rebuilt; the "Kd cliff at 500" conclusion was wrong for
  an hour. Rebuild (or full-build) before believing any probe; the ledgers were
  regenerated fresh-binary only.
- **The Bash tool collapses backslash escapes in heredocs** (`\\t` → literal tab →
  "newline in constant" C++ errors, twice). Write patch scripts to files with the
  Write tool and run them; never inline multi-line code with escapes in Bash.
- **Silent `str.replace` is a landmine**: two doc/print edits no-opped because the
  anchor text had drifted; the li/q0 reports and the fusor print went missing until
  measured. Assert every programmatic replace.
- **Q-inflation cannot fix a systematic model error** (S12): NIS ~120 wasn't noise —
  it was the slow-pole/fast-mode structure. Find the mode; then decide what Q covers.
- **Truth-feedback ablation is the sharpest instrument**: truth-fed clean + EKF-fed
  sick isolated filter-vs-loop in one run, twice (S12's pumping, S13's post-ramp).
- **Calibrate in the operator's own discretization, and subtract BC parts** (S14's
  two receipted transport-calibration bugs).
